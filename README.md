# SENTINEL FLUX

**Real-time anomaly detection system for EUR/USD forex data.**

Sentinel Flux ingests 1-minute OHLCV candlestick data, engineers 18 technical indicators, runs an ensemble ML model (Isolation Forest + Z-score voting), and surfaces anomalies through an interactive Streamlit dashboard with a two-stage investigation system — instant technical analysis followed by optional local LLM deep analysis via Ollama.

## System Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                        DATA INGESTION                           │
│  Yahoo Finance API (EURUSD=X, 1-min OHLCV)                     │
│  └─ Fallback: Synthetic random-walk generator                   │
└────────────────────────┬────────────────────────────────────────┘
                         │ DataFrame [timestamp, open, high,
                         │            low, close, volume]
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                     FEATURE PIPELINE                            │
│  engineer_features()  → 18 technical indicators                 │
│  normalize_features() → StandardScaler (zero mean, unit var)    │
│  dropna()             → removes warm-up rows (first ~49)        │
└────────────────────────┬────────────────────────────────────────┘
                         │ ML-ready DataFrame (~191 rows)
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                    ANOMALY DETECTION                            │
│  Isolation Forest  (n_estimators=100, contamination=0.05)       │
│  Z-score threshold (threshold=2.5, any feature breach)          │
│  Ensemble voting   (1+ vote → anomaly label)                    │
│  Confidence score  (IF_score + Z_binary) / 2.0  ∈ [0, 1]       │
└────────────────────────┬────────────────────────────────────────┘
                         │ results [+ anomaly_score, + is_anomaly]
                         ▼
┌─────────────────────────────────────────────────────────────────┐
│                   STREAMLIT DASHBOARD                           │
│  Metrics · Price chart · Anomaly table                          │
│                         │                                       │
│              [Select row to investigate]                        │
│                         │                                       │
│           ┌─────────────┴──────────────┐                       │
│           │                            │                        │
│  Technical Analyzer             LLM Analyzer                    │
│  (instant, rule-based)      (Ollama, local LLM)                │
│  RSI · BB · Z-score         Prose market analysis               │
│  Volatility · MACD · SMA    4-6 sentences                      │
└─────────────────────────────────────────────────────────────────┘
```

**Data flow summary:** Raw OHLCV → 18 features → normalized → Isolation Forest + Z-score ensemble → anomaly labels + confidence scores → dashboard visualization → on-demand two-layer investigation.

## Installation

### Prerequisites

- Python 3.12+
- Windows, macOS, or Linux
- (Optional) [Ollama](https://ollama.ai) for Deep Analysis

### Steps

```bash
# 1. Clone repository
git clone https://github.com/Anshul4321/sentinel-flux.git
cd sentinel-flux

# 2. Create virtual environment
python -m venv venv

# Windows
.\venv\Scripts\Activate.ps1

# macOS / Linux
source venv/bin/activate

# 3. Install dependencies
pip install -r config/requirements.txt
```

### Ollama Setup (Optional)

For Deep Analysis, install Ollama:

```bash
# Download installer: https://ollama.ai
# Then pull a model:

ollama pull llama3.2        # Recommended: 3B params, ~2 GB
# or
ollama pull llama3.2:1b     # Faster: 1B params, ~700 MB
```

Ollama starts automatically and serves at `http://localhost:11434`.

## Data Pipeline

### 1. Data Ingestion

**File:** `src/ingestion/data_fetcher.py`

Fetches EUR/USD OHLCV from Yahoo Finance. On any API failure, falls back to synthetic data generator.

```python
from src.ingestion.data_fetcher import get_forex_data

df = get_forex_data(days=1)  # Returns DataFrame: timestamp, open, high, low, close, volume
```

**Output:** 240 OHLCV rows (1-minute intervals)

### 2. Feature Engineering

**File:** `src/feature_pipeline/feature_engineer.py`

Computes 18 technical indicators and normalizes with StandardScaler.

| # | Feature | Type |
|---|---|---|
| 1 | Returns | Calculated |
| 2-5 | SMA(20), SMA(50), EMA(20), RSI(14) | Moving averages & oscillators |
| 6 | ATR(14) | Volatility |
| 7 | Rolling volatility | Volatility |
| 8-9 | Z-score returns, Z-score volume | Statistical |
| 10-12 | Bollinger Bands (upper, lower, position) | Support/Resistance |
| 13-15 | MACD (line, signal, histogram) | Momentum |
| 16-18 | Price change %, High-low %, Log volume | Price action |

```python
engineer = FeatureEngineer()
df_ml = engineer.prepare_for_ml(df, fit=True)  # Returns 191 normalized, NaN-free rows
```

### 3. Anomaly Detection

**File:** `src/models/ensemble.py`

Isolation Forest (100 trees, 5% contamination) + Z-score voting.

```python
manager = EnsembleManager()
manager.train_on_history(df_ml)
results = manager.predict_batch(df_ml)  # DataFrame with anomaly_score, is_anomaly
```

**Output:** 26-27 anomalies detected (13-14% rate)

## Investigation Agents

### Technical Analyzer

Rule-based, instant. Checks which indicators triggered the anomaly.

| Rule | Trigger | Severity |
|---|---|---|
| RSI Overbought | RSI > 70 | HIGH |
| RSI Oversold | RSI < 30 | HIGH |
| BB Breach | close > bb_upper OR close < bb_lower | HIGH |
| Z-Score Breach | \|z_score\| > 2.0 | HIGH |
| Volatility Spike | volatility > 1.5 σ above mean | HIGH |
| MACD Crossover | Histogram sign change | MEDIUM |
| SMA Deviation | \|close - SMA(20)\| / SMA(20) > 0.15% | LOW |
| Isolation Forest | ML ensemble vote | HIGH |

**Risk Level:**
- CRITICAL: ≥1 CRITICAL trigger OR ≥3 HIGH triggers
- HIGH: ≥2 HIGH triggers
- MEDIUM: 1 HIGH trigger
- LOW: No HIGH/CRITICAL triggers

### LLM Analyzer (Optional)

Calls local Ollama model for prose explanation. No cloud API required.

**Model:** `llama3.2` (or selected from sidebar)

**Output:** 4-6 sentence market analysis

```
"Based on the ensemble anomaly detection system's findings, it appears that the 
EUR/USD price movement around 1.1416 is likely a case of overbought conditions, 
with the RSI (14) value exceeding 70, indicating a high level of momentum and 
potential reversal or exhaustion in the market..."
```

## Configuration

### Environment Variables

No required environment variables. Optional `.env` file:

```bash
# .env
# Deep Analysis uses local Ollama — no API key needed
OLLAMA_HOST=http://localhost:11434
OLLAMA_MODEL=llama3.2
```

### Adjustable Parameters

Edit source files to change:

| Parameter | File | Default | Effect |
|---|---|---|---|
| `contamination` | `models/anomaly_detector.py` | `0.05` | Expected % of anomalies |
| `zscore_threshold` | `models/anomaly_detector.py` | `2.5` | Z-score cutoff |
| `n_estimators` | `models/anomaly_detector.py` | `100` | IF trees |
| `confidence_threshold` | `models/anomaly_detector.py` | `0.65` | Alert cutoff |
| `cache TTL` | `dashboard/app.py` | `300 s` | Data cache duration |
| `Ollama model` | `agents/llm_analyzer.py` | `llama3.2` | LLM to use |

## Known Limitations

**Yahoo Finance rate limiting.** The free API frequently rate-limits 1-minute forex data. System falls back to synthetic data automatically.

**Synthetic data changes per session.** After refresh or server restart, synthetic random walk produces a new price path.

**No persistent storage.** All results live in memory. No database backend.

**FastAPI backend not implemented.** The `src/api/` directory is a placeholder.

**Ollama analysis is session-only.** Results stored in `st.session_state` and lost on browser close.

**Tested on Windows 11.** Compatibility with macOS and Linux expected but not verified.

## Usage Examples

### Quick Start

```python
# 1. Fetch data
from src.ingestion.data_fetcher import get_forex_data
df = get_forex_data(days=1)

# 2. Engineer features
from src.feature_pipeline.feature_engineer import FeatureEngineer
engineer = FeatureEngineer()
df_ml = engineer.prepare_for_ml(df, fit=True)

# 3. Train model
from src.models.ensemble import EnsembleManager
manager = EnsembleManager()
manager.train_on_history(df_ml)

# 4. Detect anomalies
results = manager.predict_batch(df_ml)
print(results[results['is_anomaly'] == 1])
```

### Investigation Workflow

```python
# Technical analysis
from src.agents.technical_analyzer import TechnicalAnalyzer
analyzer = TechnicalAnalyzer()
analysis = analyzer.analyze(anomaly_row, raw_for_ml)

# Deep analysis (if Ollama running)
from src.agents.llm_analyzer import LLMAnalyzer
if LLMAnalyzer.is_available():
    llm = LLMAnalyzer(model="llama3.2")
    prose = llm.analyze(
        timestamp=anomaly_row['timestamp'],
        price=anomaly_row['close'],
        confidence=anomaly_row['anomaly_score'],
        indicator_readings=analysis['indicator_readings'],
        triggers=analysis['triggers'],
        risk_level=analysis['risk_level']
    )
    print(prose)
```
